# Employee Management System (MERN Stack)

A modern, full-stack Employee Management System built using MongoDB, Express.js, React, Node.js, and Tailwind CSS.

## Features
- **JWT Authentication:** Secure Admin Login and Registration
- **Employee CRUD Operations:** Add, Edit, Filter, and Delete employees
- **Interactive Dashboard:** Live analytics for staff counts and department statistics
- **Modern UI:** Styled with Tailwind CSS Dark Theme

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, React Router, Axios, Lucide Icons
- **Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose, JWT, BcryptJS
